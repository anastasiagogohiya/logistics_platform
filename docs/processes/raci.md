# 📊 Матрица RACI

| Задача | Руководство | Системный аналитик | Логисты | IT-команда | Перевозчики |
|--------|---|-----------------|---------|------------|-------------|
| Формирование бизнес-целей | A | C | C | I | I |
| Сбор и анализ требований | A | R | C | C | I |
| Формирование бизнес-требований | A | R | C | I | I |
| Моделирование AS-IS / TO-BE процессов | I | R/A | C | I | I |
| Проектирование архитектуры | I | C | I | R/A | I |
| Разработка AI-агента | I | C | I | R/A | I |
| Интеграция внешних сервисов | I | C | I | R/A | I |
| Тестирование платформы | I | C | R | A/R | I |
| Внедрение системы | A | C | R | C | I |
| Обучение пользователей | A | C | R | C | I |
| Поддержка и развитие | I | C | C | R/A | I |


**Расшифровка:** 
- **R** — Responsible (Исполнитель)
- **A** — Accountable (Ответственный) 
- **C** — Consulted (Консультирует) 
- **I** — Informed (Информируется)
