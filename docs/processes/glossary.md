## Глоссарий (Glossary)

| Термин          | Определение                                                                         |
|-----------------|-------------------------------------------------------------------------------------|
| **BRD**         | Business Requirements Document — документ с бизнес-требованиями                     |
| **SRS**         | Software Requirements Specification — документ с функциональными и нефункциональными требованиями к системе |
| **Acceptance Criteria**        | Критерии приемки функциональности                                                                  |
| **NER**         | Named Entity Recognition — распознавание именованных сущностей                      |
| **Стейкхолдер** | Заинтересованная сторона проекта                                                    |
| **Тариф**       | Стоимость перевозки для конкретного маршрута и веса                                 |
| **Перевозчик**  | Компания/ИП, оказывающая услуги перевозки                                           |
| **MVP**         | Minimum Viable Product — минимально жизнеспособный продукт                          |
| **RACI**        | Матрица ответственности                                                             |
