# Release Notes v1.0.0
## Logistics Platform — AI-ассистент для автоматизации перевозок

**Дата релиза:** 20.12.2026

**Версия:** 1.0.0

---

## 🚀 Что нового

| **Модуль** | **Что добавлено** | **Для кого** |
|------------|-------------------|--------------|
| **Регистрация** | Пользователи могут регистрироваться с email и паролем | Клиенты |
| **Авторизация** | Вход в систему, JWT-токены, обновление сессии | Клиенты |
| **AI-чат** | Оформление заявки через диалог с AI-ассистентом | Клиенты |
| **Поиск тарифов** | Подбор вариантов перевозки по параметрам (город, вес, тип груза) | Клиенты |
| **Заказы** | Создание заказа, просмотр истории, отслеживание статуса | Клиенты |
| **Оплата** | Интеграция с платежным сервисом (карты, счета) | Клиенты |
| **Администрирование** | Управление перевозчиками и тарифами | Администраторы |
