## 🚨 Инциденты и их обработка

### 1. Пользователь не может зарегистрироваться

| **Что делать** | **Действие** |
|----------------|--------------|
| **Симптом** | Ошибка "Пользователь с таким email уже существует" |
| **Причина** | Email уже зарегистрирован в системе |
| **Решение** | Предложить восстановить пароль или использовать другой email |
| **Эскалация** | Если пользователь утверждает, что не регистрировался → передать в IT-безопасность |

---

### 2. Пользователь не может войти

| **Что делать** | **Действие** |
|----------------|--------------|
| **Симптом** | Ошибка "Неверный email или пароль" |
| **Причина** | Неправильный пароль или пользователь не зарегистрирован |
| **Решение** | Сбросить пароль через "Забыли пароль?" |
| **Эскалация** | Если сброс не работает → передать разработчикам в Jira (Bug) |

---

### 3. AI не распознает параметры перевозки

| **Что делать** | **Действие** |
|----------------|--------------|
| **Симптом** | AI не понимает запрос, просит уточнить |
| **Причина** | В запросе нет города, веса или типа груза |
| **Решение** | Попросить пользователя уточнить параметры |
| **Эскалация** | Если AI постоянно не распознает корректные запросы → завести Bug в Jira |

---

### 4. Оплата не проходит

| **Что делать** | **Действие** |
|----------------|--------------|
| **Симптом** | Ошибка при оплате |
| **Причина** | Недостаточно средств, ошибка платежного шлюза |
| **Решение** | Попросить пользователя попробовать другой способ оплаты |
| **Эскалация** | Если ошибка повторяется → передать в IT-безопасность |

---

### 5. Ошибка 500 (Internal Server Error)

| **Что делать** | **Действие** |
|----------------|--------------|
| **Симптом** | Ошибка 500 на любой странице |
| **Причина** | Сбой на сервере |
| **Решение** | Перезагрузить страницу, если не помогает → сообщить разработчикам |
| **Эскалация** | Немедленно передать разработчикам в Jira (Bug, Critical) |
